# 🌟 Capstone Project — MediGuide

<div align="center">

<img src="./assets/mediguide-banner.png" width="100%">

</div>

## 🏥 AI Healthcare Assistant

MediGuide is an AI-powered healthcare assistant designed to help users understand symptoms, discover healthcare providers, and manage appointments through an intuitive web application.

### Features

- 🤖 AI Symptom Checker
- 🩺 Severity-based Recommendations
- 🏥 Doctor & Hospital Directory
- 📍 Smart Search & Filters
- 📅 Appointment Booking
- 🔒 Secure Authentication
- ⭐ Reviews & Ratings
- 📱 Responsive Design
